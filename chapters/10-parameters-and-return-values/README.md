# Chapter 10 — Parameters and return values

Companion code and exercises for Chapter 10 of *Foundations in C*.

## Material

- [Square](examples/square/) — pass one argument and return a calculated value
- [Larger value](examples/larger/) — declare a function before `main` and define it afterwards
- [Fare calculation](examples/fare-calculation/) — receive an `int` and return a `double`
- [Range function](exercises/range-function/) — implement and test an inclusive three-parameter check

The chapter distinguishes arguments from parameters, demonstrates pass-by-value and requires every reachable path of a non-`void` function to return a value.
