# Chapter 6 — Talking to the programme

Companion code and exercises for Chapter 6 of *Foundations in C*.

## Material

- [Age](examples/age/) — read one decimal integer and check the conversion result
- [Temperature](examples/temperature/) — separate conversion validation from domain validation
- [Quantity reader](exercises/quantity-reader/) — build a checked reader for values from 0 through 100

These controlled, single-value examples use `scanf`. Later chapters replace this introductory method with line-based input and explicit conversion.
