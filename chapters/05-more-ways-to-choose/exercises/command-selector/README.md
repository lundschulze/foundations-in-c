# Exercise — Command selector

Complete `starter.c` with a `switch` that selects Open, Save, Print or Exit for command values 1 through 4. Use `default` for every other value.

```bash
make starter
./starter
```

Test `1`, `4` and an invalid value. Predict the output before each run and explain why every ordinary case ends with `break`.

Compare your work with one possible solution:

```bash
make answer
./answer
```

The supplied value prints:

```text
Open selected.
```
