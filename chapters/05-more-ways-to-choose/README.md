# Chapter 5 — More ways to choose

Companion code and exercises for Chapter 5 of *Foundations in C*.

## Material

- [Choice](examples/choice/) — select one exact integer case with `switch`
- [Rating](examples/rating/) — use character constants as case values
- [Fare](examples/fare/) — choose between two values with the conditional operator
- [Command selector](exercises/command-selector/) — build and test a compact four-command menu

The chapter compares `switch`, `if` and the conditional operator and explains `case` labels, `break`, `default` and fall-through.
