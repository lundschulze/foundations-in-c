# Chapter 8 — for, do while and loop control

Companion code and exercises for Chapter 8 of *Foundations in C*.

## Material

- [Steps](examples/steps/) — keep a counted progression inside a `for` statement
- [At least one pass](examples/do-while/) — check the condition after the body
- [Stop with break](examples/break/) — leave the nearest loop
- [Odd values](examples/odd/) — skip the rest of a pass with `continue`
- [Multiplication line](exercises/multiplication-line/) — validate input and print twelve products

The chapter compares `for`, `while` and `do while` and introduces deliberate uses of `break` and `continue`.
