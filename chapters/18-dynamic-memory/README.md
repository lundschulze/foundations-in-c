# Chapter 18 — Dynamic memory

This chapter requests storage at run time, checks every request and gives each allocation one clear owner.

## Examples

- [`allocate-numbers`](examples/allocate-numbers) — allocate, use and release an integer array.
- [`calloc-counters`](examples/calloc-counters) — begin with zeroed integer storage.
- [`grow-list`](examples/grow-list) — resize safely through a temporary pointer.

## Exercise

- [`growing-list`](exercises/growing-list) — grow a two-element allocation to five elements.
