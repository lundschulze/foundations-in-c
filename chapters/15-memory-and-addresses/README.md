# Chapter 15 — Memory and addresses

This chapter connects an object's type and value with its storage, size, lifetime and address.

## Examples

- [`address`](examples/address) — obtain and display an object's address.
- [`object-sizes`](examples/object-sizes) — inspect implementation-dependent object sizes.

## Exercise

- [`object-inspector`](exercises/object-inspector) — print the values, sizes and addresses of several objects.

Printed addresses may differ on every run.
