# Chapter 13 — Strings in C

Companion code and exercises for Chapter 13 of *Foundations in C*.

## Material

- [Name](examples/name/) — inspect a null-terminated character array
- [Uppercase first](examples/uppercase-first/) — modify one character while preserving the terminator
- [Greeting](examples/greeting/) — read bounded text with `fgets` and remove a retained newline
- [Line inspector](exercises/line-inspector/) — report text, length, first character and newline capacity

The chapter distinguishes character and string literals, array capacity and text length, and introduces `strlen`, `fgets` and `strcspn`.
