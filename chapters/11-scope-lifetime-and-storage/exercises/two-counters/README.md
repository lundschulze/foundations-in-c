# Exercise — Two counters

Create one function with an automatic local counter and another with a static local counter. Initialise, increment and print each counter, then call both functions three times.

```bash
make starter
./starter
```

Compare your work with one possible solution:

```bash
make answer
./answer
```

Expected answer output:

```text
Automatic: 1
Static: 1
Automatic: 1
Static: 2
Automatic: 1
Static: 3
```

Both counter names have block scope. Their different storage durations explain the different results.
