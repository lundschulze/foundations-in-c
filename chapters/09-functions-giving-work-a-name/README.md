# Chapter 9 — Functions — giving work a name

Companion code and exercises for Chapter 9 of *Foundations in C*.

## Material

- [Banner](examples/banner/) — define and call a function that performs fixed work
- [Countdown function](examples/countdown-function/) — move a complete loop into a named function
- [Status display](exercises/status-display/) — organise a small programme into three single-purpose functions

The examples introduce function definitions, `void` return types, `(void)` parameter lists, function calls and clear responsibilities.
