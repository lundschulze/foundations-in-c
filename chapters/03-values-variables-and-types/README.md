# Chapter 3 — Values, variables and types

Companion code and exercises for Chapter 3 of *Foundations in C*.

## Material

- [Variables](examples/variables/) — initialise and print values of type `int`, `double` and `char`
- [Calculation](examples/calculation/) — use named integer objects in an expression
- [Supply calculator](exercises/supply-calculator/) — calculate the number of meals required

The chapter distinguishes literals, variables, types, initialisation, assignment and expressions.
