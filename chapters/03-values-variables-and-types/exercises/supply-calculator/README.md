# Exercise — Supply calculator

Create a programme with initialised integer variables for:

- the number of travellers;
- the number of meals per traveller; and
- the number of spare meals.

Calculate the total and print it with `%i`. Use descriptive names and one declaration per statement.

## Work with the starter

```bash
make starter
./starter
```

Complete `starter.c`, then rebuild it.

## Check the completed answer

```bash
make answer
./answer
```

Expected answer output:

```text
Meals required: 17
```

`answer.c` contains one possible solution. Try the exercise before opening it.
