# Exercise — Luggage decision

Complete `starter.c` so that a negative weight is invalid, a weight from 0 through 20 is accepted and a larger weight is rejected as too heavy.

```bash
make starter
./starter
```

Test `-1`, `0`, `20` and `21`. Predict each result before running it.

Compare your work with one possible solution:

```bash
make answer
./answer
```

