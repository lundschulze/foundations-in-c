# Chapter 12 — Arrays — ordered collections

Companion code and exercises for Chapter 12 of *Foundations in C*.

## Material

- [Readings](examples/readings/) — derive an array count and visit every valid index
- [Sum readings](examples/sum-readings/) — accumulate all elements
- [Print readings](examples/print-readings/) — pass an array together with its element count
- [Weekly analyser](exercises/weekly-analyser/) — print, total and find the boundaries of seven measurements

The chapter introduces fixed-size arrays, zero-based indices, `sizeof`, `size_t`, partial initialisation and the array-and-count interface.
