# Readings

The array contains five `int` elements. The element count is derived from the complete array instead of repeated manually.

```bash
make readings
./readings
```

Expected output:

```text
Reading 0: 12
Reading 1: 15
Reading 2: 14
Reading 3: 18
Reading 4: 16
```

The condition uses `index < count` because `count` itself is not a valid index.
