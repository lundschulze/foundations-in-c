# Exercise — Weekly analyser

Create seven integer measurements, derive their count and use valid indices to print every value, calculate the total and find the smallest and largest values.

```bash
make starter
./starter
```

Compare your work with one possible solution:

```bash
make answer
./answer
```

The supplied measurements produce:

```text
Total: 103
Smallest: 11
Largest: 18
```

Test increasing and decreasing sequences and repeated smallest or largest values. Changing the initialiser list must not require a loop-boundary edit.
