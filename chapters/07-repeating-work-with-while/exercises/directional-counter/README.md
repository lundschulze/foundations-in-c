# Exercise — Directional counter

Complete `starter.c` so a positive value counts down to 1, a negative value counts up to -1 and zero prints `Already at zero.`

```bash
make starter
./starter
```

Verify the starting values `3`, `-3` and `0`. Each loop needs an initial state, a condition and an update that makes progress towards termination.

Compare your work with one possible solution:

```bash
make answer
./answer
```

The supplied value `3` prints:

