# Chapter 7 — Repeating work with while

Companion code and exercises for Chapter 7 of *Foundations in C*.

## Material

- [Countdown](examples/countdown/) — trace a `while` loop through every pass
- [Total](examples/total/) — accumulate input until a sentinel value is entered
- [Directional counter](exercises/directional-counter/) — count towards zero from a positive, negative or zero starting value

The chapter focuses on initial state, continuation conditions, progress steps, counters, accumulators and boundary testing.
