# Chapter 2 — A C programme, one line at a time

Companion code and exercises for Chapter 2 of *Foundations in C*.

## Material

- [The opening programme](../01-before-the-first-line/hello/) — the programme examined line by line in this chapter
- [Using `puts`](examples/puts/) — write a fixed line of text
- [Two-line greeting](exercises/please-remain-calm/) — modify the original programme using both `printf` and `puts`

The examples introduce source-file structure, `main`, standard output, format strings, escape sequences and successful programme termination.
