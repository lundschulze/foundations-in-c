# Exercise — Add a second line

Modify the starter programme so that it writes:

```text
Hello, world!
Ready to begin.
```

Use `puts` for each fixed line.

## Work with the starter

```bash
make starter
./starter
```

Edit `starter.c`, save it and repeat the commands.

## Check the completed answer

```bash
make answer
./answer
```

`answer.c` contains one possible solution. Try the exercise before opening it.
