# Chapter 16 — Pointers without panic

This chapter stores addresses in pointer objects and uses them to inspect or deliberately modify caller-owned objects.

## Examples

- [`pointer-basics`](examples/pointer-basics) — reach one integer by name and by pointer.
- [`increment`](examples/increment) — modify a caller-owned integer.
- [`swap`](examples/swap) — exchange two caller-owned values.

## Exercise

- [`bounded-adjustment`](exercises/bounded-adjustment) — clamp a value through a pointer parameter.
