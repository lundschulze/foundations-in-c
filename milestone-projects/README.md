# Milestone Projects

Milestone projects are independent assignments that combine ideas from several chapters. They are designed for exploration and synthesis rather than reproduction of one approved answer.

Each project provides:

- a clear prerequisite range;
- requirements and acceptance examples;
- suggested implementation milestones;
- optional extensions;
- self-review questions;
- a small, compilable starter where useful.

Milestone projects deliberately do not include a complete reference implementation or automated behavioural assessment. The learner decides how to structure the solution and reviews it against the stated requirements.
