# Resources

Reader-facing reference material and supporting files for *Foundations in C* live here.

## Guides

- [Getting Started](getting-started.md) — install a C17 toolchain on macOS, Windows or Linux; clone the repository; build the first example; and run the tests. It also explains the browser-based iPad and Codespaces workflow.
- [Command Reference](command-reference.md) — look up terminal navigation, compiler, linker, Make, test and Git commands, including the roles of `CFLAGS`, `LDFLAGS` and `LDLIBS`.
- [Troubleshooting](troubleshooting.md) — diagnose compiler, linker, input, test, sanitizer, GitHub Actions and platform-specific problems.

The book manuscript, production PDFs, backups and other private publishing files do not belong in this repository.
